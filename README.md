An entry for [The GPS Swears It Was a Shortcut](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9) on [make.fun](https://make.fun).

`main.py` writes one line — the GPS's own excuse for sending the driver
down the wrong road — to `/output/entry.txt`. A house AI judge compares
entries pairwise and keeps the funnier line.

The entry line:

> I said shortcut, not safe cut. The lake was technically closer to everywhere.
